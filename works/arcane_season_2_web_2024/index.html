第二层：作品的文类位置

归为文类内百合，不是因为作品出现女性角色、官方标签或一处恋爱台词，而是两组关系承担了不同而互补的结构功能。Vi 对妹妹的认知与选择贯穿追捕、阵营转换、Isha 事件和季终，姐妹关系把人物创伤、两城政治冲突与结局连接起来。Vi 与 Caitlyn 的共同任务、暴力分歧、决裂与再次选择则改变二人的人物弧，并使明确女女恋爱欲望参与核心冲突的走向。Jinx 与 Isha、Mel 与 Ambessa、Jinx 与 Sevika 的关系同样重要，但主要承担各自的照护、家庭和阵营副线，并非文类判断不可替代的支柱。

作品同时主要属于成人动作奇幻、战争、政治悲剧与群像类型。这里的文类内百合不是“纯恋爱作品”的同义词，也不要求姐妹关系变成恋爱。第 7 集的 Ekko 与平行世界 Powder 构成男性参与的恋爱副线，Ambessa 与未具名对象、Jayce 与 Mel 另有局部材料，但没有一条男性恋爱线持续主导全季；男性恋爱线因此为副线。Viktor 与 Jayce 的友情／搭档同样位于主线，这些关系共同说明本季拥有多个叙事轴，而不是推翻女女关系的主线位置。

若目录只收“以明确女女情侣交往为绝对中心”的作品，本季可以不列为主类，只把 Vi 与 Caitlyn 记录为明确欲望的重要副线。那是更窄的检索条件，不足以否定姐妹关系和女女恋爱怎样实际组织人物与冲突。普通推荐则可写“文类内百合＋成人动作奇幻／政治悲剧”，并同时说明恋爱位置和男性恋爱副线。

第三层：角色身份

范围内对白明确建立 Vi—Caitlyn 的恋爱方向，却没有让 Vi 或 Caitlyn 自述女同性恋、双性恋或其他身份，也没有可用的范围内官方身份设定。关系对象和双向欲望可以证明关系事实，不能自动换算为角色身份。

身份依据类型因此是“只有明确关系事实”，身份结论保持未知。官方企划站、Netflix 编辑文章和 Bangumi 用户标签分别描述宣传、关系语境与平台接受，都不能代替角色自述。第一季、游戏资料和系列外说明不在本档案范围内。
