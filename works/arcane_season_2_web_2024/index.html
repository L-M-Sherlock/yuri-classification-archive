说明

分类信息提示： 本节不展开关键剧情、转折与结局，但分类信息本身会透露关系类型、叙事位置和恋爱明确度。希望完全盲看的读者请跳过本页。

按本档案的分层口径，《英雄联盟：双城之战》第二季属于女女关系主线、按作品分类归档，置信度高。Vi 与 Powder／Jinx 的姐妹关系推动追捕、选择和季终行动，Jinx 与 Isha 的照护、Mel 与 Ambessa 的母女冲突也参与主要情节；这不是把姐妹情误写成恋爱，而是记录多种女女关系共同构成结构。

Vi 与 Caitlyn 在共同任务、决裂和重新靠近之间形成对白直接指向的女女恋爱欲望，适合寻找明确情感方向、但同时接受战争和创伤剧情的读者。现有文字没有直接命名正式交往，也没有角色身份自述。它不是只写恋爱日常的作品；官方主要使用动作奇幻、游戏改编和姐妹冲突等表述，Bangumi 的“百合”是用户标签，不能代替角色身份判断。

本季另有男性参与的恋爱副线，但没有取代姐妹主线或 Vi／Caitlyn 的重要副线位置。Caitlyn／Maddie 与 Jayce／Mel 的恋爱状态包含需要画面才能裁定的部分，本档案只记录文字材料能确认的互动及精确未知项。这个限制不削弱已明确出现的关系方向，也不许可用剧情印象补写动作。
