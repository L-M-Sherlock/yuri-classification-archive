说明

分类信息提示： 本节不展开关键剧情、转折与结局，但分类信息本身会透露关系类型、叙事位置和恋爱明确度。希望完全盲看的读者请跳过本页。

本作归为文类内百合，女女关系和女女恋爱都位于主线。 Aer 与 Neviril 从替补搭档发展为共同面对创伤、拒绝被制度拆分并选择一起离开的关系；Neviril 失去前任搭档 Amuria 的旧爱，则构成她整季创伤和重新建立关系的起点。这两组关系直接组织主角弧、主要冲突与结局，共同支撑本作的文类位置。

最高明确度为明确欲望。Aer 与 Neviril 在被分隔时互诉爱意和触碰愿望，制作方官网又明确以“恋心”解释同一场亲吻；终话二人共同前往可以自由选择的地方。正篇没有现实日常剧式的正式交往称谓，所以可以确认相互爱恋与共同终局，不能补写为已经登记的伴侣关系。Dominūra 与 Rimone 另有排他的搭档承诺和共同去向，属于重要副线的潜在恋爱。

本作的性别制度需要单独说明：所有人先以女性出生，泉前的巫女又被作品描述为尚未完成性别选择。关系、文类与现实身份不能机械换算。范围内另有 Floe 与士兵之间萌生情感的局部男性恋爱方向，因此男性恋爱线为副线。完整英文字幕和官网全话资料支持主要判断，置信度为中等；日文全季字幕和连续视听复核仍缺失。

Neviril 与 Amuria 的失去是主角关系发展的起点。Amuria 消失后，Neviril 长期无法重新进入 Pal 关系，又必须面对曾夺走旧搭档的同一危险。正篇人物把她对 Amuria 的喜欢明确区分为恋爱式喜欢，因此这段旧爱既不是一般战友回忆，也不是只因死亡而显得重要；它直接塑造 Neviril 接受 Aer 的困难。

Aer 与 Neviril 从不平等的替补关系开始。Aer 想与最优秀的巫女共同飞行，Neviril则拒绝让任何人简单填补 Amuria 的位置。二人共同重访创伤、共享风险和秘密，最终在制度要求所有人立即作出性别选择时拒绝被拆开。第 25 话的相互爱意和制作方“恋心”说明已达到明确欲望，终话共同离开又让关系承担全剧结局。

这仍不同于现实日常恋爱剧中的正式交往。作品把承诺放在是否共同飞行、是否接受强制选择以及是否前往另一个世界上，没有可核的“我们现在是恋人”称谓。严格推荐可以写“相互爱恋与共同终局”，不应补成制度化伴侣关系。

Dominūra 与 Rimone 形成平行的重要副线。她们在重大危机前相互确认是彼此的 Pal，失而复得后又把相遇视为不可替代，终话以排他搭档选择收束。相互性与连续性都很强，却没有主角组那样直接的恋心和爱意命名，因此保持潜在恋爱。Floe 与士兵之间萌生情感则只占局部，足以证明男性恋爱方向存在，却不影响女女关系主线。

第二层：作品的文类位置

《西蒙》同时属于战争科幻、宗教政治、成长、群像剧和性别寓言。归为文类内百合，不是依靠亲吻数量或主要角色外观，而是看关系怎样决定谁与谁共同驾驶、谁愿意继续战斗、谁能面对创伤，以及人物最终选择什么生活。

Neviril 与 Amuria 的旧爱启动主角创伤，Aer 与 Neviril 的新关系随后穿过共同飞行、战争命令、性别选择与终局离开。前者解释 Neviril 为何封闭，后者让她重新选择搭档、爱恋和自由；二者共同组织主角人物弧，因此实际支撑文类内百合。Dominūra 与 Rimone等关系扩展群像，但不需要机械承担同一结论。

制作方官网回顾明确出现“百合动画”宣传和“恋心”解释，公共数据库也提供 Girls Love 等入口；这些材料与正篇结构相互印证，却不能替每组关系统一定性。仪式亲吻可能主要服务驾驶和宗教功能，第 25 话隔墙亲吻则由制作方明确区分为恋爱表达，必须逐场判断。

Floe 与士兵的局部情感说明男性恋爱线为副线而非无。它没有取代 Aer 与 Neviril 的终局，也没有把全季改写成由男性恋爱组织的故事。

第三层：角色身份

角色身份保持未知，并须与作品内性别制度分开说明。官网写所有人以女性出生，同时又把泉前巫女描述为尚未完成性别选择；到泉中才选择性别并成为大人。这套神话、生理与社会制度不能直接等同于现实世界任何单一模型。

因此，不能从文类内百合推定 Aer 或 Neviril 自认女同性恋，也不能因某人后来选择成为男性便把此前关系自动改称异性恋。AniList 的 Transgender、Gender Bending 与 LGBTQ+ Themes 可以提示性别主题，不能为具体人物分配身份。关系层可以确认爱恋对象、相互性与承诺，身份层仍应保留未知。

第四层：公共标签礼仪

普通推荐可以写“女女关系主线的战争科幻群像；Aer 与 Neviril 有明确相互爱恋和共同终局，Neviril 与 Amuria 的旧爱塑造主角创伤；性别制度特殊，另有男性恋爱副线”。这比只写“百合机战”更能预告作品内容。

宽口径数据库可列百合／Girls Love，并列战争、科幻、恋爱、成长、宗教政治与性别主题。严格恋爱检索可以命中“女性呈现角色间有明确恋心”，若要求正式交往或现实身份自述，则分别应记不符合。官方查询应准确写成“主简介无标准百合类型栏，但官网制作回顾明确谈到百合动画宣传和恋心”。

最强反方解释

最有力的保留意见是：泉前巫女在世界观中尚未完成性别选择，Pal 又首先是驾驶制度，许多亲吻具有宗教或技术仪式功能；用现实的“女性之间恋爱”概括全作，可能把作品有意保留的性别不确定性压回二元框架。若检索只收“两个明确自认女性的人正式交往”，本作不应无条件命中。

这项解释能够推翻“每名泉前角色都是女同性恋”“每对 Pal 都是情侣”或“亲吻数量证明恋爱”等过强说法，也提醒读者不能用最终性别选择倒推此前身份。它却不能推翻文类内百合：作品仍以女性出生并作为少女生活的角色群为情感中心，制作侧自己回顾过百合宣传，第 25 话亲吻又被明确解释为恋心，主角爱恋贯穿创伤、重新选择与终局。最准确的结论是文类成立、身份开放、仪式亲吻与恋爱亲吻逐场区分。
