在本项目的开放口径下，这部 OVA 可归入女女关系主线、按作品分类归档的百合相关作品；恋爱明确度为非恋爱，置信度中等。《非常偶像Key》是机器人少女为了“成为人类”而寻找三万名朋友、并进入偶像产业的科幻悬疑故事；现实情感支点是 Key 与中学旧友厨川樱的重逢、同居、互相扶助和共同推进偶像活动。樱救出 Key、让她住下，后来还成立以 Key 为中心的事务所并担任经理。两人的女女友情和共同生活持续推动情节，因此“女女关系主线”记录的是作品的人物组织方式，不是把偶像或机器人题材误写成恋爱。

这部作品不满足“明确女女交往”这一严格检索条件。范围内公开官方简介尚无可核的告白、恋人称谓、正式交往或女性角色的性取向身份自述；Key 与樱的关系可读作深厚友情、选择家庭和工作搭档。它也没有一条明确的男性恋爱线取代这段女女关系。对只寻找告白、接吻或已确认伴侣的读者，应标为“不命中”；对愿意阅读 1990 年代实验性科幻、女女共同生活与强烈友情的读者，可以纳入，但不应把樱的照顾和同居自动改写成恋爱事实。

最稳妥的一句话是：一部把机器人、人类、偶像工业和超自然谜团缠在一起的长篇 OVA；Key 与樱的女女友情／共同生活是情感主线，恋爱在范围内缺席，官方和三个主要资料库也没有直接把它标为百合或 GL。作品含有暴力、血腥、裸体、性化凝视、成人影像产业剥削和人体实验等内容，推荐时应一并提示。

Key 与樱的关系时间线

Key 先从乡村来到东京，目标是寻找三万名真心朋友。樱是她唯一有明确过去联系的女性朋友，也是最早把她从危险处境中带回日常生活的人。樱提供住所、工作上的照看和现实判断，Key 则以自己的异常能力和对“朋友”的单纯理解影响樱。两人因此不是单向的救援者与被救援者：樱投入劳动和风险，Key 的存在又迫使樱不断重新判断信任、责任和界限。

共同生活并不总是顺利。官方 Ver.6 摘要写到 Key 离开樱家，樱需要借助州一调查监视者；Ver.14 又明确写樱因 Key 的异常行动而害怕。把这段关系说成“始终无冲突的理想友情”同样不准确。它包含争执、误解、分离和担心，但这些动态仍首先属于朋友、室友和合作伙伴关系。把复杂性保留下来，反而比用恋爱一词把所有情感压平更能解释剧情。

女女共同体与家庭身世

Key 的身世线并非只有男性科学家和企业反派。最终篇通过巳真家族的女性记忆、研究成果和家庭创伤解释 Key 的存在；这一层与樱在东京提供的现实照护形成对照：前者讨论血缘、创造和记忆，后者讨论朋友、选择和共同生活。它们都是女女关系与家庭关系的重要素材，但都没有被写成恋爱。

偶像产业中的美浦、红子、樱等女性角色也被置于不同的控制与展示位置。Key 对美浦的偶像形象抱有憧憬，樱则负责帮助 Key 进入这一产业；这更像偶像、观众、经纪和被利用者之间的结构关系，而不是女女情侣网络。报告把这些人物作为女性共同体和产业关系的背景，不把舞台上的女性凝视、裸体或性化画面当作欲望证据。
