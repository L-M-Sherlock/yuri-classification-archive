说明

分类信息提示： 本节不展开关键剧情、转折与结局，但分类信息本身会透露关系类型、叙事位置和恋爱明确度。希望完全盲看的读者请跳过本页。

这部 OVA 属于文类内百合：女女关系位于主线，但范围内没有女女恋爱，最高明确度为非恋爱，结论置信度高。 Key 为了“成为人类”前往东京并试图获得三万人的支持，真正让这个抽象目标进入日常生活的，是中学旧友厨川樱：她收留 Key，与她共同面对危险和生活摩擦，又成立 Production KEY 推进偶像活动。二人的重逢、同居、冲突后重新选择、共同工作与终局归属贯穿全篇，直接组织 Key 的人物弧、主要行动和结局。因此，“主线”说明这段关系对全作结构不可替代，不等于宣布二人是情侣。

完整台词反复把 Key—樱命名为 friend／friendship。与此同时，樱把自己的计划放到 Key 获得幸福之后，Key 在最重要的时刻总去找樱，并以不愿被留下、归入家人墓地和永远相伴的语言收束关系。这些材料足以支持选择家庭和私人浪漫化阅读，却仍没有女女欲望、告白、恋人称谓、正式交往或性取向身份自述。只找明确 GL 的读者不应把它当作命中项；寻找女性友情、共同生活、选择家庭和黑暗科幻关系剧的读者可以纳入。

完整文本还显示两项必须分别记录的事实：母系线不是单纯温和的“家庭照护”，而是母亲保护、代际力量、实验伤害和人性封存并存；男性恋爱线则位于副线。樱—州一与 Miho—Tsurugi 都留下未完成的男女方向，Mima—Tomiko 有明确婚姻回忆，但这些线没有取代 Key—樱的中心位置。

“非恋爱”来自文本定位，不是由没有搜到某个关键词机械推出。 Ver.3 与 Ver.15 分别直接使用 friend 和 friendship，官方简介也把二人写成中学同学、共同生活者和经理／艺人搭档。终局的“不愿独自留下”和“永远在一起”给私人浪漫化阅读留下很大空间，却没有出现恋爱欲望、求偶、恋人称谓或交往确认。现有材料最充分支持双向友情与选择家庭；把它读成潜在爱情可以成立为读者解读，但不足以把恋爱写成正篇事实。

Key 与母亲 Toyoko 的关系必须同时保留照护与伤害。 Toyoko 的意愿是保护婴儿 Key，她留下的 geist 也长期守护沉睡的人类 Key；然而祖父和 Wakagi 的实施方式把历代巳真家女性的 geist 封入 Key，使她失去对自己人性的控制。这段母女关系因而同时包含母爱、代际继承和创伤，“母系共同体”不能概括成无冲突的关怀网络。Key 与母亲在终局互相承诺再见，说明这条亲情有回应，但不取消被成年人替她决定人生的伤害。

Key—Miho 是重要的女性镜像，不是第二条恋爱线。 Key 仰望 Miho，维护她想象中的真实内心；二人又被母亲的摇篮曲、偶像舞台和“谁是人、谁是机器人”的问题连在一起。终场相遇的说话人没有在 ASS 中稳定标注，所以相互性保留。它能解释 Key 为何走向偶像舞台，不能证明欲望或伴侣关系。

男性关系需要单独记录。樱—州一与 Miho—Tsurugi 都达到“明显但未确认的方向”，Mima—Tomiko 则明确建立婚姻。三者合计足以把男性恋爱线改为副线；但全作没有让这些关系接管 Key 的人物弧、樱的主要选择或终局情感落点，因此不能写成并列或主导。

第二层：作品的文类位置

《非常偶像Key》首先是原创科幻悬疑 OVA，也同时属于机器人／机甲、偶像产业、心理剧、宗教与企业阴谋、身体及意识实验叙事。“三万名朋友”这一目标把人际认可、偶像工业和超自然 geist 机制连进同一条剧情线。若查询是“明确女女恋爱类型”，本作不命中；若查询是“女性关系是否组织主角的行动、日常与结局”，本作明确命中。

Key—樱关系承载东京生活的入口、偶像计划的现实执行、冲突后的重新选择、最终危机和 Key 是否愿意成为人类。即使删除所有浪漫读法，这条关系仍不可从因果链中移除。正因为二人的持续选择直接组织人物弧、主要冲突和结局，本报告将作品归入文类内百合，而不只把它当成文类之外的私人配对阅读。母女代际线和 Key—Miho 镜像又让“女性关系主线”不只等于单一配对，而是同时涉及朋友、选择家庭、母女、偶像和继承。

男性恋爱副线会影响推荐，却没有取代这一结构。Miho—Tsurugi 的旧情与师生控制、Mima—Tomiko 的婚姻和樱—州一的未完成方向分别服务偶像工业、身世谜团和危机回应；它们不是 Key 与某名男性建立的主导恋爱弧。对规避一切男女感情材料的读者，应明确提示“有副线”，而不是为了维护某种“纯度”把它们删除。

第三层：角色身份

最强反方解释

最有力的狭义解释是：这是一部科幻、偶像与机器人阴谋剧，Key—樱从头到尾被叫作朋友；终局的生死承诺和精神相伴仍可由选择家庭吸收，因此不应放进以女女爱情为核心的 GL 书目。 官方档案没有百合／GL字面，MAL、AniList 和 Anime-Planet 的精确条目也未列相应类型字段；范围内反而有 Miho—Tsurugi 的旧情方向、Mima—Tomiko 的婚姻和樱—州一的未完成可能。这个解释保护“我只想找明确女性恋爱”的查询，也能推翻“Key 与樱是官方情侣”“本作没有男性感情材料”两种过度说法。

反方向的竞争读法也必须保留：同居、把对方幸福置于自己未来之前、最关键时刻总去找她、要求归入家人墓地，以及“这次永远在一起”，连成了一条很强的浪漫化结构。它足以支持私人百合阅读，却仍缺少明确欲望、求偶或伴侣命名；片尾歌词的叙述者和对象也不能只靠字幕锁定为 Key—樱。当前材料没有日文台本、明确说话人资料或视听材料所能提供的恋爱自述、交往确认或无法由友情／选择家庭解释的连续求偶结构；若这些范围内证据出现，现有明确度判断可能改变。画面亲密本身仍不能自动替角色完成身份自述。
