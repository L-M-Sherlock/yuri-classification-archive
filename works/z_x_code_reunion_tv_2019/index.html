本作首先是女子校背景下的科幻战斗／搭档群像。角色被赋予 partner Z/X 身份、不同队伍需要合作，疾病治疗、监视和异世界威胁使“能否信任伙伴”成为反复出现的叙事问题。女女关系主线并不表示所有角色之间都存在恋爱，也不排除作品同时属于战斗、奇幻、学校和团队成长类型；它只是指出梓—莉盖尔的关系不是由男性恋爱主线替代的次要装饰。

梓与莉盖尔的关系推动战斗机制、人物成长和最后的共同选择，E 组女性共同体则推动后半段救回同伴的行动和结局。二者不是可以从主要故事中删去的装饰，因此足以支持文类内百合。与此同时，面向明确恋爱作品的目录可以不收录本作，因为正篇尚未确认情侣关系。前一种判断回答“女性关系是否组织全剧”，后一种判断回答“恋爱关系是否已经成立”，答案不同并不矛盾。
