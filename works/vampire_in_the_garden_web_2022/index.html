说明

分类信息提示： 本节不展开关键剧情、转折与结局，但分类信息本身会透露关系类型、叙事位置和恋爱明确度。希望完全盲看的读者请跳过本页。

人类少女 Momo 与吸血鬼女王 Fine 在战争中相遇，共同逃离各自阵营，寻找人类与吸血鬼能够共存的地方。她们的同行、音乐、照护、分离和彼此带来的改变贯穿五集，直接组织主要行动、人物成长与结局；Fine 曾爱过人类女性 Aria 的往事，又解释了她为何退出战争、向往和平，并怎样理解 Momo。因此，本档归为文类内百合，由当下的双女主关系和过去的女女爱意共同支撑。

女女关系和恋爱均位于主线，最高明确度为明确欲望：Fine 直接说自己曾爱过 Aria。Momo 与 Fine 的关系则属于潜在恋爱，双方没有互称恋人、彼此告白或正式交往；把过去爱意直接移植到当下主角关系会抹去 Momo 自己的成长。作品没有男性恋爱线，也没有角色以女同性恋、双性恋等身份自述。年龄、阅历和权力差异需要在推荐时说明；结论置信度为中。

第二层：作品的文类位置

本作归为文类内百合，因为两条女女关系共同组织人物弧、核心冲突和结局。Momo 与 Fine 的相遇使逃离成为可能，她们寻找共存之地的行动贯穿五集；Fine 对 Aria 的过去爱意则解释她为何拒绝战争、珍视音乐，又为何起初把 Momo 当成过去之人的影子。结局必须同时回答 Fine 如何面对 Aria 的创伤，以及她是否真正看见 Momo 本人。

反战、末世、吸血鬼奇幻、逃亡和音乐是作品的重叠文类，不是与女女关系分离的背景。两族禁忌决定 Fine 与 Aria 的悲剧，也决定 Momo 与 Fine 为什么必须逃离；音乐则把过去恋人、旧友遗物和当下关系联系起来。完整五集没有建立男性恋爱线，因此不存在男性爱情取代女女关系中心的问题。

第三层：角色身份

Fine 对 Aria 的爱是明确关系事实，但 Fine、Momo 和 Aria 都没有在范围内以女同性恋、双性恋或其他性取向自述身份，官方资料也没有相应身份设定。爱过一名女性能够确认这段欲望的方向，不能自动规定角色应使用哪个现实身份词。

同样，Momo 与 Fine 的潜在恋爱不能替双方完成身份声明。报告可以准确写“Fine 曾爱过女性”“Momo 与 Fine 的主线关系有明显但未确认的恋爱指向”，却不能进一步声称三位角色已有明确性取向身份。

第四层：公共标签礼仪

普通推荐可以写“文类内百合的末世反战奇幻：Momo 与 Fine 是潜在恋爱的双女主主线，Fine 与 Aria 有过去的明确女女爱意”。这能让寻找女性关系主线或明确女女欲望的读者找到作品，同时避免把 Momo 与 Fine 宣传成已经交往。

官方查询应写“所核页面未使用百合／Girls Love 字面，但官方简介称 Fine 曾爱过人类”。Bangumi 的百合标记属于用户标签，AniList 与 MAL 未列相应类型只是各站入口不同。私人阅读可以围绕 Momo 与 Fine 的同行、保护、替身问题和悲剧告别展开，但年龄、力量和阅历差异不能被浪漫气氛遮住。

最强反方解释

最有力的保守读法是：Momo 与 Fine 是反战逃亡故事中的朋友、搭档和选择家庭，明确恋爱只属于 Fine 与已故的 Aria。这个读法有充分依据：当下双主角没有互称恋人、彼此告白或交往承诺，Fine 对 Aria 的爱却由本人直接说出。它能推翻“Momo 与 Fine 已经交往”或“所有照护与牺牲都等于恋爱”的说法，也提醒读者正视替身开端和权力差异。

但这项解释不能把 Momo 与 Fine 降成偶然同行。二人的相遇、逃离、音乐、分离、救援和相互改变组织五集主要选择；Fine 是否把 Momo 当作独立的人，又与她如何面对 Aria 的创伤直接相连。即使把当下关系解释为深厚友情，作品仍然以女女关系为核心，并以过去明确女女爱意支撑人物动机。

因此，本档同时保留两项结论：Fine 与 Aria 达到明确欲望，Momo 与 Fine 保持潜在恋爱。若同一五集范围出现能够确认 Momo 与 Fine 彼此告白、正式交往或 Aria 对等欲望的可靠视听证据，相关关系判断可能不同；现有平台标签数量不能代替这些事实。
