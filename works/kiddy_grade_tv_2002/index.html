无剧透结论

按“女性关系是否构成作品的主要叙事与情感结构”这一口径，本作属于女性关系主线且按作品分类归档，置信度高。 两名女性主角 Éclair 与 Lumière 从第一话到结局始终作为行动搭档、记忆见证者和生死共同体出现；她们反复选择彼此，关系同时承载任务剧、身份谜团、反抗组织和重新面对过去等核心情节。全季没有持续发展的男性恋爱主线来取代这组关系。

它不满足“明确女女恋爱”严格检索。 TV 正篇没有双方告白、确认恋人／交往、以恋爱为目的的接吻，也没有女同性恋或双性恋身份明示。文本能够直接确认的是长期伙伴关系、相互依赖、优先保护、共同工作和高频相处；把这些进一步读成潜在恋爱有充分抓手，但仍是对关系性质的推断，而不是正篇已经宣布的事实。

因此最准确的短标签不是“明确情侣”，也不是“只有观众二创”：它是女性双主角关系居于主线的科幻动作／太空歌剧，可作女性关系主线且按作品分类归档推荐；恋爱明确度保持开放。 对只找确定恋爱者应明确排除，对接受关系中心型百合、长期搭档或未命名亲密关系的读者则可以推荐。

第一层：文本中的关系

r01天使特警：主要女性关系搭档／恋爱主线潜在／明显但未确认的恋爱指向双向正篇事实＋强推断＋读者解读长期伙伴关系，可作潜在恋爱阅读，未确认交往

Éclair—Lumière 的正篇事实。 两人不只是同属一个单位：她们共享远超当下身体寿命的过去，见证彼此记忆丧失与身份变化，也在制度要求、个人创伤和生死危机中反复重新选择“搭档”。第 11 话的“我们是搭档”、第 16 话失忆后的“我比任何人都了解你”、第 20 话的优先救治、第 22 话的共同赴险和第 24 话的“只要与你一起”，形成从身份、情感到行动的一条连续证据链。

相互性也不是靠单一高光场景推断。Lumière 害怕再次失去 Éclair，在她与组织决裂时站到其身边；Éclair 在 Lumière 的生命危机中明确调整优先顺位，并在终局继续把二人的配合当作能够行动的条件。她们各自都保护、依赖和选择对方，故“相互性：双向”是关系事实，而不是对恋爱性质的判断。

没有被正篇确认的部分。 全 24 话没有告白、正式交往、恋人称谓或性取向自述。第 20 话的口对口接触由字幕直接解释为给药，不能脱离医疗语境计作亲吻。第 16 话“姐妹”是对外掩护，不是血缘设定，但揭穿伪装也不会自动证明恋爱。二人表现出的不可替代、长期共同工作与最终继续并肩，支持潜在恋爱读法；它仍必须与“长期伙伴／亲密友人／选择的家人”解释并列。

作品也提供了避免过度解释的日常反证。Éclair 说每天都要见 Lumière，也希望偶尔透气；Lumière 表示不喜欢过分黏连。这不是否定爱与关心，而是说明亲密关系里存在独立空间。把所有关心都浪漫化，会丢失这组关系作为成熟搭档的具体层次。

身体与身份变化要放回科幻叙事层。第 12 话的 D command 令纳米细胞膨胀并威胁摧毁器官，后段又明确区分原本人物、复制体、新身体以及身体与记忆的适配问题；这些不是“关系变化”的隐喻证据。能够支撑关系连续性的，是二人在不同阶段仍保有共同记忆并重新选择搭档身份，而不是“换过身体”这件事本身。

第二层：作品的文类位置

本作首先是原创科幻动作、太空歌剧、超能力搭档剧和阶级政治寓言。早期以任务单元剧建立银河组织与 ES 成员，中后段转入特权阶层、难民、制度暴力、复制身体、记忆和反叛。官方、MAL 与 AniList 的科幻／太空／动作字段准确描述了这些骨架。

但“科幻是主类”不等于“女性关系只能是次要配料”。24 话几乎一直由 Éclair 与 Lumière 的双人视角组织：世界观经由她们执行任务而展开，制度转折经由她们共同反抗而发生，Éclair 的身世需要 Lumière 作为记忆见证者才能重建，Lumière 的存亡又成为 Éclair 在后段的重要个人目标。结局不是将两人拆开进入别的家庭或恋爱终局，而是让她们重新回到共同班次。女性关系因此达到叙事主线，而非局部可删的读者联想。

依本档案的开放工作定义——女性之间具有叙事或审美重要性的关系构成作品中心，且不被男性恋爱主线取代——本作可列为女性关系主线且按作品分类归档。这里的“主类”是关系结构判断，不是声称剧情主线是恋爱，也不是改写官方营销。与之并列的数据库主标签仍应优先保留科幻、动作、太空歌剧、超能力与原创动画。

男性人物数量很多，但“男性情感材料存在”和“男性恋爱线主导”是两个不同变量。第 5 话的邀约没有跨话发展；Armbrust 在第 18、19 话两次对包含 Éclair 在内的复数对象使用英译 love，却没有得到告白回应或进入约会／交往情节；Chevalier 对 Éclair 的感情又由正篇揭示为非血缘母子。为避免把这些材料抹掉，本报告将男性恋爱线记为“次要”，同时限定为含混且未发展；它没有取代双主角关系。

第三层：角色身份

  • Éclair 与 Lumière 是长期、双向、彼此优先的女性搭档：正篇明示。
  • 两人是否对彼此有恋爱欲望、是否将共同关系理解为恋爱：未明示；可作有文本抓手的推断或私人阅读。
  • 两人是否自我认同为女同性恋、双性恋、无性恋或其他身份：未知。
  • Tweedledee 希望与 Lumière 更亲近：局部台词事实；欲望类别和后续关系未知。
  • Alv—Dvergr、Éclair—Chevalier：正篇分别给出母女、养母子关系，不能因强烈依恋或牺牲而挪作恋爱证据。

作品文类标签不能替角色完成身份自述。反过来，没有身份明示也不妨碍记录具体关系在全剧中的中心性。推荐者应分别写“这是女性关系中心作品”和“角色性取向未知”，两者并不矛盾。

身体更替、复制人与记忆恢复也不能替角色完成性别或性取向自述。TV 正篇用这些机制讨论人格连续性、组织控制和创伤记忆；本报告只据其确认人物经历及关系延续，不把身体变化本身登记成恋爱或身份类别证据。

第四层：公共标签礼仪

  • 官方字段：写“官方播出／发行资料未标百合／GL，以科幻动画和双主角并列宣传为主”。“未标”只说明未见该字段，不能写成官方否认百合。
  • 普通推荐：可写“女性双主角长期搭档关系贯穿全剧的科幻太空歌剧；按关系中心口径属于女性关系主线且按作品分类归档，恋爱未确认”。
  • 数据库主标签：优先列科幻、动作、太空、超能力、原创；百合／Yuri 可作为重要关系标签。只写“百合恋爱”会隐去作品的大部分类型信息。
  • 严格恋爱检索：不纳入明确情侣、告白、浪漫接吻或身份明示清单；可纳入“潜在恋爱／关系未命名”分栏。
  • 私人阅读：将长期共同历史、失去恐惧、相互优先和结局并肩理解为爱情，有连续文本依据；公开陈述时仍应标明正篇没有命名恋爱。

AniList 的 Yuri 相关度和 Bangumi 的百合用户标签说明这种读法已经形成稳定公共入口；MAL 的类型字段沉默则说明站点会把同一作品优先组织为科幻。两种记录可以同时为真，不需要用标签数量裁决文本。

最强反方解释

最有力的排除意见是：Éclair 与 Lumière 是科幻搭档剧中的战友／亲密友人，作品从未要求观众把她们理解成恋人。 “partner” 是 ES 成员的行动编制；共同任务、相互救命和害怕失去都能由战友情解释。第 5、6 话还让二人主动保留独处空间，第 16 话的对外姐妹身份可强化家人式读法，第 20 话唯一的口对口接触是医疗给药。官方未用百合／GL 宣传，MAL 也只列科幻、机械、太空和超能力。若百合被严格限定为明确女性恋爱，本作应排除。

本报告接受这套解释对恋爱明确度的限制：它足以推翻“双方已恋爱”“存在浪漫接吻”“已交往”“角色身份明示”等说法，也提醒推荐者不能把社区百合标签当作官方类型；报告因此没有把二人写成情侣。它不能推翻的是关系中心性：Éclair 与 Lumière 的共同视角覆盖全季，彼此的记忆、身份、阵营选择、身体危机和终局行动互相嵌套，作品最终又以二人继续共同班次收束。即使完整采用“非恋爱终身搭档”解释，女性之间的重要关系仍是作品的主要叙事和审美对象；依本档案不把百合等同于已确认恋爱的工作定义，结论仍是“女性关系主线且按作品分类归档、关系可作非恋爱或潜在恋爱双重阅读”。

另一种保留意见是把“百合”降为重要次级标签：全剧更大的因果骨架是银河政治、阶级压迫和组织反叛，二人关系只是承载这些事件的主角配置，而非作品真正讨论的主题。这可以解释官方与 MAL 为什么优先标科幻，也足以要求数据库把 Sci-Fi／Action 放在最前。但“女性关系主线归档”在本档案中判断的是女性关系是否居于叙事中心，不要求作品唯一讨论恋爱或关系本身；双主角关系若被抽走，身份谜团、反叛和结局都需整体重写。因此本报告不把它降为局部或纯读者联想。

分用途结论

用途分类
普通作品推荐女性双主角长期搭档关系贯穿全剧的科幻动作／太空歌剧；可按关系中心口径推荐为女性关系主线且按作品分类归档，须说明恋爱未确认
数据库主标签科幻／动作／太空歌剧／超能力／原创为主要类型；百合／Yuri 宜作重要关系标签
严格明确恋爱检索不纳入：无双方告白、恋人／交往确认、浪漫接吻或身份明示
私人百合阅读文本抓手充分：长期共同历史、双向选择、彼此优先和结局并肩均有正篇依据；关系性质保持开放
角色身份检索未知：只确认具体关系与行动，不替 Éclair、Lumière 补写性取向身份
官方分类查询官方未标百合／GL；同期官方资料确认 24 话 TV 范围并持续并列宣传两名主角

最短的可复制推荐语是：

《天使特警》TV 版是以 Éclair 与 Lumière 的长期女性搭档关系为主线的科幻太空歌剧，可按关系中心口径归入女性关系主线且按作品分类归档；二人双向且彼此优先，但正篇没有确认恋爱、交往或性取向身份。

方法、来源与限制

  • 范围控制。 只纳入 2002—2003 年 TV 正式第 1—24 话。富士电视台保留终局梗概，MAL、AniList 与 Bangumi 均记 24 话，Bangumi 话数 API 又返回 24 项且全部为 type 0。三部 2007 年总集篇电影、《キディ・ガーランド》及其他续作、宣传与影碟附加内容、漫画、小说、广播和其他跨媒介材料一律排除。

  • 字幕覆盖。 重新下载并逐话核对 Subf2m 的 DHD Blu-ray 英语 ASS：24 份文件共 623,065 bytes、6,085 条 Dialogue，字符格式均为 UTF-8 BOM、LF 换行。压缩包、逐文件及规范化清单 SHA-256 均写入 metadata.json；正文的六组计数由逐文件事件数重新求和，不以关键词命中替代完整剧情核对。

  • 来源状态。 富士电视台、FlyingDog、MAL、AniList GraphQL、Bangumi 页面及 API、Subf2m 与 Jimaku 当前目录于 2026-07-30 重查。Anime-Planet 仍返回 Cloudflare 验证页，Jimaku 未发现精确条目；两者分别记为“未复核”和“无匹配”，不以搜索片段补字段。

  • 语言与视听限制。 未取得完整日文字幕、对应视频或日语音轨；时间码来自英语 ASS，中文经英语中转自译，不反推 partner、love 等词的唯一日文含义。动作、说话人及亲属关系只在连续对白足以辨认时陈述，画面、构图、沉默反应和动作发起者不作独立证据。

  • 结论边界。 身体更替、复制人与记忆恢复按科幻机制记录，不自动升级恋爱或身份判断。高置信度针对女性搭档关系居于主线、相互选择、男性情感材料次要且未发展、官方未标百合／GL及身份未知；“潜在恋爱”只是可连贯阅读。严格结论若要改为明确，仍需在这 24 话内出现恋爱命名、交往／恋人确认、浪漫亲吻或身份明示。

  • 数据库标签恢复（2026-07-30）：Anime-Planet 精确条目已通过验证后的交互式浏览器读取完整 Tags 面板；此前自动 HTTP 403／验证页记录只保留为传输历史，不再表示字段未知。
