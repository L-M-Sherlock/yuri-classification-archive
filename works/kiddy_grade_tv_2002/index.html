低剧透概览

说明

分类信息提示： 本节不展开关键剧情、转折与结局，但分类信息本身会透露关系类型、叙事位置和恋爱明确度。希望完全盲看的读者请跳过本页。

本作归档为文类内百合，置信度高。Éclair 与 Lumière 的长期女性搭档关系贯穿二十四话：二人共同执行任务、见证彼此的记忆与身份变化，并在组织冲突和生死危机中持续选择对方。这组关系直接组织双主角的人物弧、主要冲突和结局，因而不是可以从科幻主线中删去的装饰。作品同时属于科幻动作、太空歌剧和政治寓言；这些文类与女女关系主线并不互斥。

范围内的女女恋爱位于主线，最高明确度为潜在恋爱。二人彼此信赖、害怕失去对方、在危机中把对方置于优先位置，并最终继续并肩生活和工作；这些事实支持明显但未确认的恋爱阅读。正篇没有告白、恋人称谓、确认交往或性取向自述，唯一的口对口接触也被剧情说明为医疗给药。因此本作适合接受长期搭档与未命名亲密关系的读者，不符合明确女女恋爱或明确身份检索。

第一层：文本中的关系

Éclair 与 Lumière 的关系并非由一个高光场景成立。Lumière 在 Éclair 失控和反抗组织时害怕再次失去她、继续站到她身边；当 Éclair 失去记忆，Lumière承担起解释过去和帮助她重建自我的责任。Éclair 则在 Lumière 生命垂危时明确调整优先顺位、主动求助，并在终战中继续把二人的配合作为行动条件。相互照料、信赖和选择分别来自双方，因此相互性为双向。

恋爱判断保留竞争解释。二人的长期共同历史、彼此不可替代、失去恐惧与结局并肩形成明显但未确认的恋爱指向；同一批事实也能由亲密友人、终身搭档或选择的家人解释。正篇没有告白、交往、恋人称谓或身份自述，医疗给药也不能剪成浪漫亲吻，所以不把她们写成已确认情侣。

第二层：作品的文类位置

Éclair 与 Lumière 的搭档关系支撑文类内百合的归档。世界观通过二人的共同任务展开，组织反叛由她们的阵营选择推动；Éclair 的身份谜团需要 Lumière 作为记忆见证者才能解开，Lumière 的生命危机又成为 Éclair 后段的重要个人目标。终局仍由二人的协作完成，尾声让她们回到共同班次。这组关系因而组织人物弧、核心冲突和结局，而不是只在局部提供亲密气氛。

本作同时首先是一部科幻动作、太空歌剧、超能力搭档剧和阶级政治寓言。科幻机制提供身体更替、记忆与制度暴力等冲突，双主角关系使这些冲突落到人物选择上；将作品归入文类内百合，不等于把其他文类降为背景，也不声称恋爱是唯一剧情主线。

男性恋爱线为副线。第 5 话的男性邀约没有跨话发展，Armbrust 的含混情感表达指向复数对象，没有得到告白回应，也没有进入约会或交往情节；Chevalier 对 Éclair 的感情则被正篇明确为母子关系。这些材料应保留，但没有取代 Éclair 与 Lumière 的主线关系。

第三层：角色身份

正篇能够高置信度确认 Éclair 与 Lumière 是长期、双向、彼此优先的女性搭档；能够谨慎支持二人关系存在未命名的恋爱方向。范围内没有女同性恋、双性恋、无性恋等身份自述，所核官方资料也没有提供相应身份设定，因此角色身份保持未知。作品文类、具体关系和平台标签都不能替角色完成身份说明。

身体更替、复制人与记忆恢复用于讨论人格连续性、组织控制和创伤记忆。它们能说明人物经历与关系为何需要重新确认，却不能单独证明恋爱或性取向。

第四层：公共标签礼仪

普通推荐可写“女性双主角长期搭档关系贯穿全剧的科幻太空歌剧，归档为文类内百合，恋爱未确认”。数据库应并列科幻、动作、太空、超能力与百合关系标签，而不是只留下其中一组。严格恋爱检索不应把二人列为明确情侣；私人阅读可以依据共同历史、相互优先与结局并肩理解为爱情，但须保留长期搭档等竞争解释。

官方播出和发行资料所核未见百合／GL 或恋爱表述，只能记为“官方未标”。AniList 的 Yuri 入口与 Bangumi 的百合标签说明这种阅读具有公共可见性；它们不把角色投票成恋人，也不改写官方措辞。

最强反方解释

最有力的狭义解释是：Éclair 与 Lumière 是科幻搭档剧中的战友或亲密友人，partner 是 ES 成员的行动编制；共同任务、互相救命和害怕失去都能由战友情解释。二人会主动保留独处空间，对外“姐妹”身份只是掩护，唯一的口对口接触又是医疗给药。官方未用百合／GL 宣传，MAL 与 Anime-Planet 也优先列科幻类型。若“百合”只指明确女性恋爱，本作不应进入该检索栏。

这套解释足以推翻“已确认恋爱、存在浪漫亲吻、已经交往或身份明示”等主张，本报告接受这些限制。它不能推翻关系的叙事中心性：两人的共同视角覆盖全季，彼此的记忆、身份、阵营选择、生命危机与终局行动互相嵌套；即使完整采用非恋爱终身搭档解释，女女关系仍在组织作品。因此它不改变文类内百合的开放归档，只会限制严格恋爱检索。

另一项保留意见是把百合降为关系副标签，因为银河政治、阶级压迫和组织反叛提供了更大的因果骨架。这能解释官方和多个数据库为何优先标科幻，也提醒推荐时必须并列作品的直接文类。但若抽走 Éclair 与 Lumière 的共同历史和持续选择，身份谜团、反叛动机与结局均需整体重写；二人的关系不是可替换的主角配置，因此仍达到主线位置。
