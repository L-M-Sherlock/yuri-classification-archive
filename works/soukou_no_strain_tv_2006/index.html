Sara 与 Emily 的关系不是静态陪伴：Sara 先把 Emily 当作唯一能够承接真实身份的对象，Emily 随后说明 Sara 的命名和每日谈话结束了自己的孤独；身份真相揭开后，二人仍分别拒绝被哥哥或族群带回原处，转而再次选择彼此。她们在决战前共同承担风险，最后也以继续在一起而非回归原有家庭作为生存答案。恋爱读法因此有连续文本抓手，但朋友、搭档与选择家庭仍是正篇明确提供的竞争解释。

Lavinia 的局部追求提供了更直接、却更窄的女女欲望事实。她的“最喜欢”和独占计划足以确认单向明确欲望，但没有 Sara 的相应选择；藏起 Emily 和近身骚扰还要求把欲望与合意分开。Sara 与 Lottie 则相反：照料、竞争、未来约定都很强，文本却积极把它们组织为朋友、战友和搭档，因此记为非恋爱。

第二层：作品的文类位置

Sara 与 Emily 的关系参与主人公如何重建身份、为何能驾驶 Strain、如何面对 Ralph 以及结局去向，是全作真正的主线组织轴；Lavinia 的单向欲望又使女女恋爱并非完全由观众从亲密友情中推出来。这两组关系共同提供稳定的百合阅读入口。

作品整体仍主要属于战争科幻、机甲动作与家庭悲剧。最强冲突来自 Sara 对 Ralph 的追寻、背叛创伤和最终阻止，敌我战争及 Emily 族群的毁灭解释承担世界观和悲剧因果；Ralph 与 Vivian 另有男女亲密副线，但没有主导 Sara 的故事。因而本报告不把全作无条件列作百合文类，而采用文类外百合阅读：承认主线女女关系与局部明确欲望，同时保留作品更主要的机甲战争和兄妹悲剧位置。

第三层：角色身份

范围内没有 Sara、Emily、Lavinia 或 Lottie 对同性恋、双性恋等身份的自述，也没有所核官方材料的身份设定。Lavinia 对 Sara 的明确欲望只能证明这段欲望的对象，Sara 与 Emily 的共同选择也只能支持关系层判断；两者都不能自动换算成稳定性取向。角色身份因此为未知。

第四层：公共标签礼仪

官方所核首页只使用“SF美少女机甲动作”表述；Bangumi 的“百合”是普通用户 tag，AniList 的 Yuri 54 是带 rank 的相关性标签，MyAnimeList 则未列 Girls Love。普通推荐可以说“机甲战争主线，含主线女女搭档与单向明确女女欲望”；数据库主标签以科幻、机甲、战争、戏剧为先，百合适合作为有限定的次级入口。严格恋爱检索应直接写清没有正式女女交往、只有 Lavinia 的单向明确欲望，而私人阅读可以进一步采用 Sara—Emily 的明显但未确认的恋爱方向。

最强反方解释

最强的狭义解释会把 Sara 与 Emily 完全理解为创伤后的朋友、驾驶搭档与选择家庭：Sara 自己使用“朋友”和“搭档”，Emily 的孤独、命名和永远相伴也可由照护关系解释；两人没有告白、接吻、恋人称谓或正式交往。Lavinia 的追求集中在一话喜剧，并包含欺骗、骚扰和没有回应的独占，因此不应让局部欲望替全作定类。这个解释足以拒绝“文类内百合”和严格双向恋爱检索，也可能把主线恋爱位置降为缺席、只保留局部单向欲望。

它不能抹除 Lavinia 直接指向 Sara 的“最喜欢”和独占愿望，也不能解释为什么 Sara 与 Emily 的排他选择、分离重选、永远相伴与共同结局持续占据核心节点。因此，文类外百合阅读仍比“完全没有百合入口”更能保留现有差异。若出现范围内日文台词校正，证明关键英文关系词方向不同，或官方角色资料直接确认恋人／非恋人关系，当前恋爱明确度与公共标签建议可能改变。
