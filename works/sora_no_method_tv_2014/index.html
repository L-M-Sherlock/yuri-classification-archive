说明

分类信息提示： 本节不展开关键剧情、转折与结局，但分类信息本身会透露关系类型、叙事位置和恋爱明确度。希望完全盲看的读者请跳过本页。

《天体的秩序》2014 年 TV 正篇可放入本档案的“女女关系主线”入口：古宫乃乃香回到故乡后，与诺艾尔重逢，也重新面对户川汐音、柚季和こはる等旧友。诺艾尔会在乃乃香家中等候、一起吃饭，末话还明确提到她曾在该处住宿；这类日常照看和共同生活情节与七年前的失落记忆、愿望、失联和再度相聚一起，持续组织着全作的谜团、冲突与解决。这里的“主线”仅说明女女关系在叙事中的位置，并不把它偷换成主线恋爱。

正篇对这些关系使用的是朋友、旧友、一起完成愿望和彼此相信等语言。范围内没有双方告白、情侣约定、接吻、女女欲望自述或角色的性取向身份自述；最高明确度因此是“非恋爱”，恋爱位置为“范围内缺席”。剧中偶有“喜欢／讨厌”或“恋”字，但逐一放回台词前后可见：前者是在朋友失约和是否愿意重归于好的争执中使用，后者是对乃乃香担心神情的一句玩笑，随即被否认，均不足以建立恋爱关系。

所以，寻找已确认女女交往或接受未确认恋爱方向的读者不应把本作当作命中项；寻找以多名女孩的旧友情、修复关系与共同愿望为核心的作品，则可纳入。Bangumi 的“百合”用户标签和本档案的宽入口解释了它为什么在相关榜单出现，却不能改写正篇把关系说成朋友的事实。本结论置信度为中等：13 话日文字幕已逐话核对，官网也可核对版本和群像框架；本次未同步观看视频，故不根据字幕单独断言镜头、肢体动作或表演细节。

这种连续性解释了为什么它值得进入“女女关系主线”的检索入口，也解释了为什么不能因没有恋爱成立就当作无关。反过来，正篇反复自行给出“朋友”“大家”“一起”的关系语言；这些不是一个古板闸门，却是公共描述不能跳过的文本事实。把乃乃香—诺艾尔或乃乃香—汐音读出比友情更强的感情，是可讨论的阅读；若把它升级为“已确认恋爱”，就会把关系的感染力和可核对的关系名混为一件事。

第二层：作品的文类位置

《天体的秩序》是围绕故乡、超自然谜团、失落记忆与旧友重聚展开的原创 TV 动画。主体并非一条恋爱关系，而是由女孩们承担大部分情感轴的群像关系：乃乃香与诺艾尔的相遇给出谜团入口，乃乃香与汐音的和解给出冲突的出口，其他朋友对愿望的不同理解让群体重新能够行动。男性角色湊太是旧伙伴和柚季的兄长，也参与群体；但他没有取代女女关系成为情感主线，也没有带出一条已建立的男性恋爱线。

把它归为“作品分类”并不是在替所有数据库立法，而是说明本档案的一个明确检索用途：读者若想找女孩之间的关系会如何承受遗忘、伤害、照料、离别和重新选择，本作会给出丰富而持续的文本。对于想找明确 GL 情侣的人，这个入口过宽，必须同时显示“恋爱范围内缺席”；对于只承认已确立恋爱才允许进入任何百合目录的读者，它又会显得过宽。两种查询都可以存在，但不应由后一种查询消除第一种查询所描述的关系位置。

官方宣传的“两名少女相遇”与故事页的“真正的朋友”同样没有裁决全部接受史。它们说明官网怎样介绍范围内版本；Bangumi 的用户标签说明一部分用户怎样检索；AniList 与 MyAnimeList 的未标说明各自没有启用相同入口。把这些不同层级并列，反而能看清本作的实际位置：它是女女关系在叙事中很居中的非恋爱群像作品，不是以明确情侣关系为卖点的作品。

第三层：角色身份

范围内没有乃乃香、诺艾尔、汐音、柚季或こはる对女同性恋、双性恋、无性恋或其他性取向作出的自述，也没有可核对的 TV 版官方身份设定。更窄地说，正篇也没有让任一女女配对确立交往。身份字段应因此保留“未知／范围内无依据”，不能由作品有女孩群像、某句“喜欢”、Bangumi 标签或观众的亲密感受直接推出。

这也不等于角色被指定为异性恋。身份未知是资料状态，不是隐藏的否定答案。第 7 话的一句“恋……吧”由于对象、语境与即时否认都不足以支持持续关系；第 8、9 话的“喜欢／讨厌”则是朋友间是否还能相处的争执。它们都提醒了同一个边界：词语是否出现在字幕里，不等于它自动回答了“谁喜欢谁、以何种关系喜欢、角色如何理解自己的身份”。

范围外的 OVA、ONA、漫画、访谈或粉丝创作即使给出另一种线索，也不能回填本报告。这里回答的是“2014 年 TV 正篇能支持什么公共表述”，而不是将整个企划和所有可能的阅读压缩为一个人物身份结论。保留不知道，既避免把女孩间亲密无端降格，也避免替角色说出她们没有说过的话。

第四层：公共标签礼仪

普通推荐可以写成：“围绕一群旧友重建信任与愿望的奇幻群像；女孩关系是主线，恋爱未建立。” 这样既保留会影响观看期待的关系信息，也不让一个宽词遮住奇幻、哀伤、记忆和和解。若平台容许多标签，较清楚的组合是“女女关系主线”“友情／共同体”“奇幻谜团”“恋爱未确认”，内容提示另列亲人死亡、失忆、朋友冲突和暂时分离。

官方查询要分成三个短问题。范围内官网未见“百合／GL”的字面类型词；所核公开简介、故事页和角色页也未见将女女关系说成恋人的措辞；官网实际给出的可核对信息是两名少女相遇与“真正的朋友”等群体关系语言。这记录的是官方网页内容，不是要求读者放弃自己的阅读，更不是说“朋友”天然不可以有复杂或酷儿的意义。

私人讨论则可以直接说明证据强度，例如：“我从乃乃香与汐音的失约、重聚和想一起看流星雨中读到恋爱感。” 这是一种可复核的读法，而非伪装成官方事实。公共数据库若要服务明确恋爱检索，应排除或显著限定本作；若要服务女孩关系主线检索，则可保留。先说明标签服务谁、再贴标签，比把平台数据当作关系真相更可靠。

最强反方解释

最强的狭义反方解释是：本作是一部带有超自然设定的朋友群像，女孩们的关系虽重要但不应进入任何百合相关目录。它能有力反对把本作推荐给明确女女恋爱读者：正篇没有告白、交往、接吻、欲望自述、恋人称谓或身份自述；官网故事页还以“真正的朋友”命名一话。若某个数据库的“百合”只服务于寻找情侣或明示女同性恋经验的人，该反方的排除规则很清楚。

不过，它不能推翻本报告较窄的归档理由。乃乃香—诺艾尔、乃乃香—汐音和朋友群体不只是偶有同框的女孩：她们的遗忘、冲突、照护、分离和重聚决定了故事要解决什么。若一个资料库同时允许读者寻找“女女关系是否位于主线”，完全删除本作会丢掉一类关系结构。这里的分歧不必伪装成谁在为关系宣判本质，而是两个不同的检索问题：一个寻找明确恋爱，另一个寻找叙事中心的女孩关系。

相反的高估也要受同一标准约束。某些读者会把“喜欢／讨厌”的追问、想与对方看流星雨、在离别中反复说想见面，读成恋爱已经被明确。那些场景确实让关系具有强烈的情感密度，却始终与旧友失约、群体愿望和“重新成为朋友”的直接台词相连。承认它们可以触发私人百合阅读，不等于应把它们改写为情侣成立。最稳妥的公开结论是：女女关系主线，恋爱未建立，私人恋爱阅读可保留并须说明为阅读。

方法、来源与限制

  1. 范围与版本。 本档案只纳入 2014 年 TV 动画正篇第 1–13 话。Bangumi 的作品资料和公开剧集 API 均显示 TV、13 个正篇条目；同一 API 另列特别篇和主题曲条目，故不混入范围。官网故事页也完整列出第 1–13 话。OVA、2019 年 ONA、漫画、小说、宣传、访谈、音乐、活动和全部跨媒介材料一律不用于补写恋爱、结局或身份。
  2. 文本材料。 Jimaku 条目 87 的日文 ASS 覆盖正文所列纳入单元；时间码只对应该字幕版本。
  3. 视听限制。 本次没有同步观看视频，因而不凭字幕断言谁先靠近、是否牵手或拥抱、镜头怎样停留、音乐怎样营造情绪。尤其不会把片头片尾歌词、下一话预告或“恋”字的一次性玩笑脱离说话对象后当作女女恋爱证据。若未来有可复核的正篇视频，最值得补查的是第 8、11、13 话的台词与镜头配合，而不是预设它会改变分类。
  4. 来源分工。 官网只记录官方实际采用的故事与营销语言；Bangumi、AniList、MyAnimeList 和 Anime-Planet 分别说明各自的社区或编辑字段。Bangumi 的约 10.10% 是“百合”标签人数除以想看、看过、在看、搁置、抛弃五种收藏状态用户总数的当日快照；不是标签用户内部占比，更不是多数意见。AniList 本次没有 Yuri 标签；Anime-Planet 的精确条目 Tags 面板也未见 GL，二者的字段沉默都不解释为否定女女关系或私人阅读。
  5. 结论强度。 “中等”置信度针对版本边界、反复出现的朋友关系语言，以及范围内没有直接情侣确认这一较窄结论；它不评判作品质量，也不否认亲密关系能带来恋爱感。未来若出现可核对、且确属 TV 正篇的剧本或视听材料，可以细化场景说明；要把恋爱或身份改为确定，仍需要与此相称的直接证据。
