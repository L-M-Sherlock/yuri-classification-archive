群体共同体是本作最稳固的关系事实。 官方将人物概括为 24 名舞台少女，而故事页也确实把不同学校的成员反复放进同一场排练、比赛或问答。对于三分钟喜剧来说，角色被重新组合本身就是叙事方式：某一话让圣翔成员试验“菜单朗读”，下一话就可能把校际对手或配角放到同一竞演中。把这种关系压成“一对主角”会漏掉本作的主要乐趣，也会误以为没有连续恋爱线就是没有女女关系。

华恋—光与双叶—香子提供较容易被配对阅读的入口。 华恋与光共享《星光》的舞台记忆，光能够作为问答主持人向华恋提问；双叶和香子则在标题明确的一话中被安排在放学后空间，香子的练习变化与同学的影响相连。这些设置支持亲密、依存、搭档和共同成长的读法，也可成为读者的私人配对对象。现有简介不足以确认恋人称谓、告白、接吻或交往承诺，关系表因此保留“未知”。

竞演不是恋爱冲突的替身。 圣翔、弗隆蒂亚和席格菲特等学校之间存在比较、挑战和互相学习；“打倒某校”是节目和舞台竞争的目标，而不是对某一位少女的情感排他。舞台剧企划本来就把对手、搭档和同台演出放在同一套词汇里，不能看到强烈情绪、夸张台词或靠近构图就自动跳过关系类型的核对。

第二层：作品的文类位置

若把“百合作品主类”理解为女女关系在作品的叙事或审美中心，而不是把恋爱确认当唯一门槛，那么本 WEB 版符合。官方公开的可见角色范围和每话简介都把舞台少女的演出、排练与校际互动放在前景；但这些摘要不足以审计整部作品是否另有男性恋爱线。喜剧、音乐、表演艺术、校园和短篇形式是并列的文类限定，而不是对女女关系判断的反证。

不过，这个主类判断需要限定媒介版本。它不是电视动画的删节版证据，也不是剧场版或手游故事的替代入口；它更像一组围绕舞台少女企划制作的短小旁支。读者若期待连贯的恋爱剧情，会发现每话的笑点和组合不断变化；读者若寻找全女群像、舞台竞演以及可以从多个关系角度阅读的轻喜剧，则会得到更贴切的推荐。数据库中的“百合”与国际站点的“Comedy／Music／Performing Arts”可以同时成立，因为它们在回答不同的检索问题。

第三层：角色身份

本 WEB 版的现有材料不足以确认角色以台词或官方人物资料明示女同性恋、双性恋、无性恋或其他性取向身份。全女阵容、舞台上的亲密、共享记忆和观众容易配对的组合都不能自动推出身份。应把角色身份记录为范围内无依据，而不是把作品的社区标签换算为角色身份证明。

同样，官方人物页列出 24 名少女，不能代替她们的恋爱或身份陈述。没有具体身份证据时，推荐可以谈“女女关系主线”“舞台少女共同体”或“可供配对阅读”，但不能写“全员女同性恋”或“官方确认她们是情侣”。这一区分对跨媒介企划尤其重要：手游、舞台和 TV 版可能使用更长的对话或不同的关系重点，但那些材料已被本报告排除。

第四层：公共标签礼仪

对普通推荐，建议写成“2019 WEB 迷你动画；全女舞台少女群像；喜剧、音乐和竞演；恋爱方向未确认”。这样既能让读者找到作品，也不会把 Bangumi 的“百合”标签误传为官方声明。

对数据库主标签，可以保留“百合”或“女女关系主线”的开放归档，同时在恋爱明确度列写“未知”，在官方字段写“所核未见”。对严格恋爱检索，不能把它列为命中；对接受友情、搭档、竞演和读者解读的读者，则可以列入候选。对角色身份检索，应写“范围内无依据”。

对私人阅读，读者当然可以把华恋—光、双叶—香子或其他组合当作配对来观看，但应明确这是读者解读，不要求所有人把同一组合称作官方情侣。对官方分类查询，当前能说的只有：官方资料强调 24 名舞台少女的迷你喜剧和配信方式，所核页面没有百合／GL 字面；官方沉默不能被夸大成否认。

最强的狭义解释是：本作只是手游企划的宣传性短篇，公开摘要以夸张笑料、舞台训练和角色客串为主，并未提供足以确认某一关系推进为恋爱的材料，因此不应放入百合作品主类。这个解释能有效提醒读者不要把“全女角色”“舞台默契”写成交往，也能说明 AniList、MAL 和 Anime-Planet 为什么更愿意使用 Comedy、Music、School、Performing Arts 等字段。

它不能推翻两个较窄但重要的事实：第一，官方故事页的每话主体确实由舞台少女之间的合作、竞演、问答和互相影响构成；第二，本项目的作品主类是一个检索用途标签，不是角色身份或恋爱事实的宣判。如果读者将“百合”限定为明确女女恋爱，当前材料不足以把本作列为命中；如果读者用它寻找女女群像、女性角色共同体和可供配对阅读的舞台作品，则将其列入并标明“恋爱方向未知”更能反映资料。

另一个反方读法会依赖电视动画或手游中华恋、光、双叶、香子等人的更长关系发展，认为这些背景已经足以解释 WEB 短篇的亲密。但这会违反本报告的媒介边界。跨媒介材料可以在另一个系列总览中讨论，不能作为本条 26 话的直接证据。只要不把其他版本倒灌回来，开放主类和严格恋爱排除就能同时成立。
