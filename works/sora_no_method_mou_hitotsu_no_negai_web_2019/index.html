第二层：作品的文类位置

这是一个约三十分钟、以奇幻愿望机制推进的 WEB 短篇。它并不重做 2014 年 TV 的全部关系史，而是把一个新角色卡萝尔放进诺艾尔与雾弥湖町朋友群体已形成的生活中，并集中处理“回去”与“留下”的冲突。就本单集可见的叙事重心而言，女女关系不是支线装饰：卡萝尔的目标、诺艾尔的愿望、生日会及最后的修复都围绕女性角色的选择组织。

按普通推荐与开放式数据库分类，本作可写作女女关系主线、作品分类依据、含明显但未确认的恋爱方向。这句话拆开了三个变量：关系在叙事中的位置是主线；恋爱读法有可说明的材料；关系的制度性名称仍未由可审计的一手文本固定。这样既不会把一篇二手复盘夸大成官方认证，也不会让字幕缺失抹去作品已被描述出的牵挂与冲突。

该分类不依赖“全女性主角”之类的捷径。男性角色可出现在世界与朋友群体中，却未成为本单集所记关系冲突的情感轴；这一点服务于“女性关系是否居中”的查询，不替任何角色推断性别或性取向。Bangumi 的用户标签、AniList 的字段与官方未标状态可以解释检索地图，不能替代这一层的关系结构分析。

第三层：角色身份

本档案没有可审计的一手字幕、剧本或范围内官方角色设定可用于登记诺艾尔、卡萝尔或其他角色的性取向。r01 的潜在恋爱方向来自二手复盘所述的个人喜欢、长久相处愿望与关系修复；它支持“存在关系推断”，不支持把任何一人写成明确女同性恋、双性恋或其他身份。

“身份未知”也不等于否定私人阅读。读者可以从卡萝尔如何围绕诺艾尔行动、如何调整愿望、以及两人如何返回生日会提出自己的解释；公共资料则应清楚标示这种解释的证据层级。把作品分类、两人的关系走向和角色身份拆开，既能避免以“友情”跳过潜在酷儿阅读，也能避免以一个情感短句替角色完成她们未作出的自我命名。

TV 正篇、BD 特典、漫画与其他跨媒介版本即使提供更明确的身份或关系资料，也属于另一个范围。本报告不借它们补强这部 WEB 单集，也不以本单集的中等置信度外推整个企划。

最强反方解释

最保守的解释是：本作是《天体的秩序》世界观中的友情续篇。卡萝尔和诺艾尔都与圆盘、愿望及离开机制有关；生日会和希望一起生活也可以被理解为朋友与同类之间的依恋。独立复盘是观后材料而非官方剧本，因此严谨的数据库可以拒绝将二手叙述当作确认情侣证据，并在严格恋爱检索中排除本作。

这套解释正确保护了两条边界。第一，不能把“最喜欢”自动译成具有唯一含义的恋爱宣言；第二，不能把复盘提到的事件、表情或剧情顺序扩展成未经复核的镜头事实。它也提醒我们，卡萝尔的最终愿望同时牵涉诺艾尔和“大家”，所以不能把共同体从结局中删掉。

但反方解释若将二手材料描述的个人追寻、害怕失去、生日会邀请和“想一直在一起”全部降为没有分类意义的背景，就会丢掉短篇为何围绕两名女性展开。较稳妥的结论不是宣告“已交往”，也不是把关系压成无差别友情，而是保留三层：女女关系在主线；恋爱方向明显但未确认；身份没有一手依据。这个结论的强度与材料强度相称，也为后续取得版本匹配文本时留下可修订的位置。
