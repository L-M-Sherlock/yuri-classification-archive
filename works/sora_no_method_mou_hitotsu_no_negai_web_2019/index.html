说明

分类信息提示： 本节不展开关键剧情、转折与结局，但分类信息本身会透露关系类型、叙事位置和恋爱明确度。希望完全盲看的读者请跳过本页。

这部单集不是一般意义上的群像后日谈：新角色卡萝尔与诺艾尔之间的去留冲突直接发动故事，并在“被拒绝”、辨认真实感受和重新许愿的连续过程中形成主线。诺艾尔与乃乃香等人的朋友／家人共同体则构成她想留下的生活，也是结局必须同时容纳的另一组关系。因此本档以女性关系主线作为作品分类依据，而不是用全女关系或社区标签替代文本判断。

范围内最高达到明确女女欲望。卡萝尔不仅被另一角色指出爱着诺艾尔，还亲口把诺艾尔称作挚爱，并希望永远在一起。诺艾尔主动邀请她共同过生日、一起回到朋友群体，却没有用同等恋爱语言确认双方交往，故相互性仍按单向记录。本作适合寻找女女欲望主线的读者，但不满足正式情侣或身份明示检索。完整英语字幕使结论置信度为高；未同步复核画面与日语音轨是最重要限制。

r01 在时间中的变化比单句“挚爱”更关键。卡萝尔起初把圆盘职责与带走诺艾尔绑定，把诺艾尔选择朋友视为拒绝；汐音的劝告迫使她区分职责、受伤感和真实愿望。她先为诺艾尔与所爱众人许愿，再明确加入自己的长久相处诉求。诺艾尔则从拒绝离开，到共同生日和主动邀请，持续回应卡萝尔作为朋友与共同体成员的归属，却没有把这种回应命名为恋爱。因此“明确欲望、单向”既保留卡萝尔的明示，也不复制到诺艾尔身上。

r02 不是 r01 的竞争对手，而是诺艾尔所选择的生活结构。乃乃香等人的生日会、家人称谓和等待，让“留在镇上”具有共同生活与持续照护的具体内容。卡萝尔最终没有要求诺艾尔在自己与大家之间二选一，而是重写愿望，使个人爱能够进入共同体。这一收束支持作品分类，却不需要把整个朋友群体恋爱化。

第二层：作品的文类位置

本作是一部由奇幻愿望机制驱动的单集后日谈，同时也是女性关系冲突剧。卡萝尔对诺艾尔的带离目标发动主要事件，她辨认并重选愿望构成角色弧，诺艾尔的朋友共同体决定冲突如何解决；移除这些关系，单集的因果链就不存在。因此女性关系与恋爱方向都位于主线。男性角色属于朋友与家庭背景，没有形成副线、并列或主导的男性恋爱结构。奇幻、日常、友情、选择家庭和单向女女爱是可并列的文类描述。

第三层：角色身份

卡萝尔明确爱诺艾尔并希望永远在一起，这是关系事实，不是固定身份自述。她没有使用女同性恋、双性恋等性取向名称，诺艾尔也没有自述恋爱或身份方向；因此身份层仍为未知，依据类型只记“有明确关系事实”。不能由 Bangumi 标签、作品分类或单向爱替两人完成自我命名。即使“挚爱”提供了比一般亲密更明确的对象方向，它仍回答卡萝尔爱谁，而不是她如何概括自己对所有人的持续性偏好。

第四层：公共标签礼仪

普通推荐可以直说“女女爱与去留冲突处于主线”，并补充“单向明确、无正式交往”。数据库主标签采用“百合／女性关系主线”有较强文本预测力，但宜并列奇幻、友情和选择家庭，避免让读者误以为这是情侣确立篇。严格恋爱检索若要求双向确认或身份明示，应排除；若目标是寻找明确女女爱或求偶方向，则应纳入。面向官方字段时，只能写视频标题与说明未使用百合、GL 或女女恋爱类型字面；这不是官方否认。

最强反方解释

最强的保守读法会把卡萝尔与诺艾尔视为同类圆盘之间的友情与归属冲突。它保护友情的独立价值和正式恋爱检索的可预测性，也能解释诺艾尔为何始终把未来表述为与“乃乃香和大家”在一起、结尾为何回到共同生日与朋友群体，而非确立排他情侣。这足以反驳“双向交往”或“共同体被恋爱取代”的说法。

但若据此把 r01 判为非恋爱，就无法解释文本连续使用“被拒绝”“你爱她”和“挚爱的诺艾尔”，也无法解释卡萝尔为何必须承认个人愿望才能完成角色弧。朋友解释与单向恋爱并不互斥：文本让卡萝尔的爱进入诺艾尔已有的共同体，而不是让两者互相消灭。因此保守读法限制的是相互性、正式关系和身份结论，不推翻明确欲望或作品层分类。同步日语台词若显示英语字幕在“爱／挚爱”处存在实质误译，才会要求下调恋爱明确度。
