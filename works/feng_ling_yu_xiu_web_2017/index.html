第一层：文本中的关系

r01风铃儿—白钰袖友情／搭档／恋爱主线潜在恋爱双向正篇事实＋强推断两人从共同游历、互救和信任发展到季末继续同行；这组关系组织双主角人物弧、主要危机与结尾去向。正篇称朋友，并以换装玩笑、相互偏爱、生命优先级和未来计划形成明显但未确认的恋爱指向，未确认明确欲望或交往

风铃儿与白钰袖首先是持续而相互的行动共同体。她们开篇已结伴游历，各自寻找失踪的师父和母亲；不是一名固定主角带着功能性助手，而是在情报、潜入、武力和情绪支撑上反复互补。风铃儿会营救被困的白钰袖、在战斗中唤回她的经验，也会在她失控和昏迷时承担风险与照料；白钰袖则为营救风铃儿进入危险据点，并在多次冲突中保护她。季终双方仍选择把下一段旅程放在一起。这里的“双向”只描述双方持续投入、选择和行动，不等于两人已互相承认恋爱。

关系又被连续放进可作恋爱理解的对话结构。风铃儿让白钰袖反复换装、赞美她年轻漂亮且武艺出色；白钰袖公开偏向风铃儿准备的惊喜，接受她对秘密的保留，并在季末称她改变了自己的人生道路。内心对话直接讨论风铃儿把白钰袖的生命置于自己之上，结尾又用一次假分离引出共同前往雪山、海域和金林的计划。这些不是同一句话的重复解释，而是观看、评价、偏爱、生命优先级和未来安排在多话累积。将它们与冒死营救和守床并置，恋爱读法比完全脱离文本的配对更有根据。

不过，第一季仍把关系留在未命名状态。最明确的直接称谓是“朋友”，现有材料没有告白、接吻、恋人、交往或性取向自述。武侠故事中的知己、侠侣式搭档和生死朋友也能表现高度忠诚，所以“恋爱指向明显”是对整组叙事选择的推断，不是把每次照料都机械翻译为爱情。

崔公子对白钰袖的单向好感构成男性恋爱副线。他因这份好感追随二人，并在旅途中有所成长；但白钰袖没有给出对等的恋爱回应，风铃儿与白钰袖的共同旅程也没有被他取代。季末同行者增加，还提醒读者“继续旅行”不是二人排他关系的证明；这项限定不会抹去双女主仍是情感与结构中心的事实。

第二层：作品的文类位置

第一季应归为文类内百合，并与武侠、冒险、动作、喜剧和悬疑重叠。关键在于风铃儿与白钰袖这组主线女女关系组织人物弧、主要危机与结尾去向；崔公子的单向好感虽需提示，却不承担同样的作品级作用。这里的关键不是“女性角色多”或“数据库有人贴百合”，而是删除中心女女关系后，作品会失去哪些组成部分。

首先，标题直接组合两名主角的姓名，官方公开简介也从风铃儿身边出现白发少女、两人不顾议论继续游历江湖展开。其次，两人各自寻找亲人的目标没有形成两部平行故事，而是逐渐被同一阴谋连接；多次行动转折由一方营救、呼喊或唤回另一方推动。再次，第一季没有在武侠案件解决后把她们的关系留作可删去的装饰，结尾仍以“是否分别”以及下一段共同旅程收束。

因此，百合与武侠不是互相排斥的两个标签：武侠提供世界、冲突和行动形式，女女关系决定观众跟随谁、危机为何具有情感重量、旅程怎样延续。即使采用“知己而非恋人”的保守读法，这一关系仍构成叙事与审美中心；但恋爱明确度需要另行标注，不能因为作品属于女女关系主线归档便倒推出第一季已经确认情侣。

男性角色参与战斗、阴谋和同行，也不使作品自动退出百合文类。真正需要检验的是男性恋爱线是否成为女主的终局目标、是否重排叙事中心。本季没有这种情况：崔公子的好感可见，却保持单向和副线地位。将其如实提示，比使用含义不清的“纯百合”更能服务推荐。

第三层：角色身份

角色身份与作品文类必须分开记录：

  • 风铃儿与白钰袖互为核心同行者，反复优先保护并选择对方：正篇关系事实；
  • 多场亲密互动共同形成恋爱指向：有文本基础的强推断；
  • 双方已经告白、接吻或正式交往：第一季未确认；
  • 任一角色自我认同为女同性恋、双性恋、无性恋或其他身份：未知；
  • 崔公子对白钰袖有单向好感：可见副线；白钰袖是否以恋爱回应，现有证据不支持。

即便 Anime-Planet 使用 GL／Baihe、AniList 使用 Yuri、Bangumi 使用百合，这些都是作品检索字段，不是角色自述。反过来，正篇没有身份词也不等于角色被确认是异性恋；它只意味着严格身份检索不能命中。

第四层：公共标签礼仪

普通推荐可写：

双女主百合武侠；相互保护与共同旅行贯穿第一季，恋爱指向明显但没有告白或正式交往，另有男性对女主之一的单向好感副线。

数据库可并列“百合、武侠、冒险、动作、原创动画”，再分别说明关系中心性、恋爱明确度、男性副线和官方表述。这样既不会因出品方页面未写 GL 就抹掉作品结构，也不会把社区标签包装成官方认证。

私人阅读可以把相互偏爱、冒险营救、持续照料、生命优先级与未来同行理解成正在形成的恋爱；公开推荐时应把这种关系性质标为推断，并把“第一季尚未确认”放在同一句中。只写“官配”会越过证据，只写“普通友情”又会遮蔽作品反复经营的暧昧方向。对于只检索明确情侣、只检索角色身份或排除男性追求者的读者，应分别给出否定结果，而不是让一个“百合”标签替所有查询作答。

最强反方解释

最有力的替代读法是：风铃儿与白钰袖属于武侠叙事中的亲密朋友、知己或侠侣式搭档，观众感到暧昧主要来自熟悉百合文类后的阅读习惯，而不是正篇已经陈述的恋爱。

这套解释有四项扎实依据。第一，字幕中最明确的关系称谓是“朋友”；第二，第一季没有两名女主之间的告白、接吻、交往或身份明示；第三，营救、守床、外貌称赞、相互偏爱和共赴江湖都可以发生在深厚友情中；第四，英语字幕能够确认台词，却不能替代视频证明表情、触碰、构图和无台词心理。三名同伴加入季末南行，也削弱了把共同旅行直接等同于二人排他伴侣关系的说法。

这项反方足以推翻“第一季已经确认女女情侣”或“每个亲密行动只能是恋爱”的强断言，也使恋爱明确度保持为潜在恋爱。它的限度在于：即使将全部亲密场面按友情解释，标题、官方简介、双主角配置、互相营救、共同谜团和季终去向仍由风铃儿与白钰袖的关系组织。它因而不能把作品降为“武侠主线中偶尔可配对”，最多改变关系性质的说明；本报告保留文类内百合归档，同时拒绝把角色身份、明确欲望和正式交往写成事实。若范围内出现能改变两人叙事中心性、明确关系命名或证明现有字幕误译的材料，当前判断才需要相应改变。

分用途结论

用途分类
普通作品推荐文类内百合；双女主武侠冒险，女女关系为主线，关系投入双向，恋爱指向明显但未确认交往
数据库主标签可加入“百合”，与武侠／冒险／动作并列；另标男性单向好感副线
严格明确恋爱检索不命中；第一季没有确认告白、接吻、正式交往或双方身份明示
私人百合阅读有跨多话互动与全季结构支持，不只是脱离文本的配对；仍应容纳知己读法
角色身份检索不命中；两名主角的性取向身份均未知
官方分类查询Bilibili 出品方页面未标百合／GL；不能把数据库标签改称官方认证
排除男性恋爱要素的检索不命中；存在男性对女主之一的单向好感，但它不主导主线或结局

  • 正篇材料。 核心文字材料来自 Anime Tosho 第一季发布页：英语 ASS 连续覆盖 E01–E12。本报告仅采用字幕文字，未作视听复核；字幕版本、语言和覆盖范围与第一季纳入范围精确对应。
  • 字幕来源核验。 Anime Tosho 的十二话英语 ASS 连续覆盖 E01–E12，与第一季纳入范围相符；Jimaku 与 Viki 的相关字段资料不足，其他版本或受限材料不进入正篇证据。该英语字幕构成本报告的全季文字覆盖。
  • 视听限制。材料不含对应视频，不能证明字幕未记录的表情、触碰、镜头、构图和无台词行动。作品标题、季界、关系称谓、连续对话和行动因果比视觉推断更可靠。英语字幕也不是本报告能够独立认证的官方台本；中文均为自行翻译或概括。综合置信度为高，但恋爱明确度仍保持“潜在恋爱”，即明显但未确认的恋爱指向。
