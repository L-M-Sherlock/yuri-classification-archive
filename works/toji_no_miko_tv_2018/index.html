2018 年 TV 版可记录为“女女关系处于主线、按作品分类归档”的开放百合相关作品，置信度中等。 官方逐话梗概从御前试合后的共同逃亡写到六名主要刀使的行动与结局阶段；它们支持女性关系是叙事组织的重要部分。刀剑战斗、政治阴谋和母辈留下的责任仍是作品的表层类型，不能被一个类别词压缩掉。

最强的双人关系是可奈美—姬和。已核对的官方梗概记录她们从救援、同行和共同战斗，延续到危机、救出与会合；这支持关系处于主线。把持续选择、共同负担和结局结构读作“潜在／明显但未确认的恋爱方向”，属于基于这些事实的强推断和读者解读，而不是官方恋爱命名。Anime字幕论坛的 SC 简中 ASS 第 01—24 话已逐集作文本审阅，可定位若干浪漫化措辞；但没有视频、画面、原始日文、同步或 ASS 空白 Name 字段的说话人归属复核，故仍不能把字幕或梗概未列的对白、接吻、交往或身份自述当作已被排除的事实。

舞衣—沙耶香、艾莲—薰以及六名主要刀使的共同体也很重要。官方梗概可定位她们的求助、搭档、共同战斗和群体支持；完整 SC 文本审阅在艾莲—薰处可定位到“最喜欢薰了”的社区中译，但 ASS Name 为空且未与日文、画面核对，不能确认说话人、互惠或恋爱。除可奈美—姬和的强推断外，其余关系的恋爱明确度仍记录为未知。只寻找范围内可定位的明确女女交往证据的读者不应把本作当作严格命中；接受女女关系主线、少女战斗群像和开放浪漫阅读的读者则可以考虑。

逐话覆盖与证据边界

官方站的故事页覆盖第 1—24 话；本报告逐话核对标题、主要事件和关系参与者，再选出上表节点。第 1—12 话主要建立逃亡、舞草和反折神行动；第 13—20 话扩展六人队伍、家庭与女神冲突；第 21—24 话集中写姬和失控、可奈美追寻、六人决战和两人重逢。SC 简中 ASS 也覆盖第 01—24 话并已逐集文本审阅。官方概要不能替代字幕文本；字幕文本也不能替代画面、语气、原始日文、同步或 ASS 空白 Name 的说话人归属复核。

“潜在恋爱／明显但未确认”来自多项事实叠加，而不是关键词计数：可奈美选择放弃安全位置去保护姬和；姬和逐渐接受可奈美和团队分担她的负担；两人被分离时彼此的行动目标和情绪都会改变；结局再次把她们放在同一条生死与归来线上。第 4、22、24 话的社区中译为这种读法提供可定位的补充，但有翻译、归属与视听边界。与此同时，所核官方资料未以恋爱术语命名这些行为，配音演员访谈也只谈共同场景与承担负担，并非身份宣告。因此报告保留浪漫解释，同时不越过“正式交往”证据门槛。
