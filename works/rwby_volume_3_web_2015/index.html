说明

分类信息提示： 本节不展开关键剧情、转折与结局，但分类信息本身会透露关系类型、叙事位置和恋爱明确度。希望完全盲看的读者请跳过本页。

本作归入文类内百合，置信度中等。 第 1–12 章均有简英双语字幕覆盖：Team RWBY 四人从 Vytal Festival 赛场延续到 Beacon 灾难，互相寻找、分工、保护和被迫分离构成主要行动骨架，因此这组女性团队关系支撑整部作品的文类位置。Ruby—Penny、Weiss—Winter 等关系则在关键节点补充信任、照护和失落。

如果检索目标是明确的女女交往、告白、接吻或性取向身份自述，本卷不作为命中。Blake—Yang 在第 8 章围绕信任和旧创伤进行直接对话，第 11–12 章又出现保护、道歉、分离后的拒谈；这些材料给潜在恋爱阅读留下空间，但没有双方告白、情侣称谓或正式交往。Ruby 在灾后对姐姐说的 “I love you” 明确处于姐妹语境，不能拿来填补女女恋爱证据。Jaune／Pyrrha、Weiss／Neptune、Blake／Sun 及 Adam 对 Blake 的占有性语言也使男性情感线并列存在。

关系事实与恋爱读法

第三季的关系重点不是一段单独的告白，而是“谁在危机中把谁当作必须保护、寻找和重新信任的人”。覆盖正式第 1–12 章的 ACG.RIP 字幕把 Team RWBY 的四人协作、姐妹照护、朋友失落和敌方控制线都纳入同一版本边界：四人从赛场延续到 Beacon 失守，女女关系承担了动作目标、公共危机和结局分离。Blake—Yang 则在这条团队主线内部出现局部高点：Blake 的过去与 Adam 的威胁成为 Yang 不能置之不理的个人问题，Yang 的保护和 Blake 对信任的重新选择又把关系后果推到结局。

完整字幕支持照料、担心、追逐、回援、道歉和共同创伤等可观察事实，但没有恋人称谓、双方告白、正式交往或接吻。把 Blake—Yang 直接写成已确认恋爱会超过证据；把它完全写成没有任何浪漫方向，也会忽略这些关系为何在灾难叙事中获得特殊重量。Ruby—Yang、Weiss—Winter 的姐妹语境，Ruby—Penny 的朋友线，以及 Cinder—Emerald 的控制型上下级关系，则有足够对白将其与恋爱读法区分开来。字幕已解决文本覆盖问题；MAL 的完整分页与政策说明也已把平台状态闭合为“无精确条目”。

还需要把“本卷的关系位置”和“整个系列的后续发展”分开。Volume 3 结尾让队伍分散，并没有替后来各卷预先命名关系；后续作品可能提供新的信息，但不应倒灌到本报告。反过来，排除后续材料也不意味着否认本卷已经出现的照料、信任和回援。这样的版本边界让读者知道：这里判断的是十二章 WEB 文本本身，而不是整个企划的最终配对答案。

第二层：作品的文类位置

官方预告把第三季的入口写成 Vytal Festival Tournament、团队战斗和新的阴谋；Bangumi 记录它是 12 章 WEB 作品并附带“百合”社区标签。本作归入文类内百合，并非因为主要角色都是少女，而是四人团队的合作、分歧、互救和被迫分离共同构成本卷的结构。她们的关系决定比赛如何协作、嫁祸后是否继续信任、Beacon 灾难中优先寻找谁，以及结局的分散为何构成损失；抽走 Team RWBY，主要人物弧、核心冲突和结局都会失去因果中心。

Blake—Yang 的创伤关系为团队主线提供局部的恋爱阅读入口，却没有取代动作奇幻、学校竞技和灾难叙事，也不单独承担整部作品的文类结论。Ruby—Weiss、Blake—Weiss、姐妹关系、朋友关系和控制型上下级关系各有自己的文本位置，不因同属女性关系而被统一恋爱化。

因此，适合的公开写法是“文类内百合的动作奇幻 WEB 动画；Team RWBY 的女性团队关系贯穿主线，Blake—Yang 为潜在恋爱，男性情感线并列”。完整字幕覆盖并未把最高明确度推到“明确交往”；只寻找已确认恋爱的读者仍应排除本卷。两种用途都应保留限定词。

第三层：角色身份
