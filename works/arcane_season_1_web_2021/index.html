说明

分类信息提示： 本节不展开关键剧情、转折与结局，但分类信息本身会透露关系类型、叙事位置和恋爱明确度。希望完全盲看的读者请跳过本页。

《Arcane》第一季归为文类内百合，女女关系位于主线，结论置信度高。这一判断由两组性质不同却互相咬合的关系支撑：Vi 与 Powder／Jinx 的姐妹亲情组织了两位核心人物的成长、创伤、追寻和全季最终冲突；Vi 与 Caitlyn 从利益合作发展出的亲密与潜在恋爱，则进入这场姐妹冲突并改变季终选择的条件。这里的文类判断依赖女女关系怎样组织叙事，不把姐妹亲情改写成恋爱，也不要求恋爱明示才能成立。

恋爱检索需要另行收窄。Vi 与 Caitlyn 有直接调情、持续照料和关于“我们”的关系追问，最高达到潜在恋爱，位于重要副线；第一季仍未让双方确认交往或性取向身份。作品同时以阶级政治、动作奇幻、科技伦理和城市悲剧为主要文类面貌，并有 Mel／Jayce 的男性恋爱副线。普通推荐应把这些信息与文类内百合并列，避免让严格寻找明确女女情侣或回避异性关系的读者产生错误预期。

Vi—Caitlyn 从囚犯与执法者的临时合作开始，随后出现 Vi 的直接调情、Caitlyn 为 Vi 承担代价、双方分享创伤以及对“我们”的追问。单项照料或共同任务都可以由友情解释；从合作、调情和照料发展到分离谈话，并在季终被迫与姐妹关系竞争，才形成明显但未确认的恋爱指向。双方没有正式关系名称，Caitlyn 的恋爱方向也未被第一季完整确认，因此相互性未确认。

Mel／Jayce 的明确异性亲密把政治联盟、个人感情与议会决策连在一起，构成男性恋爱副线。它必须纳入观看提示，却没有取代两组女女关系对 Vi、Jinx 及季终核心冲突的组织作用。

第二层：作品的文类位置

两组关系承担不同作用。Vi 与 Powder／Jinx 的姐妹关系是主线：保护、分离、追寻和重新选择同时组织两位核心人物的成长、全季最大情感冲突与结局；它是亲情而非恋爱，文类判断不改变其实际类型。Vi 与 Caitlyn 的潜在恋爱则嵌入主线：这段关系推动 Vi 的选择，也被 Jinx 体验为可能取代自己的关系，最终成为季终冲突的直接条件。两组关系共同说明，女女关系不是动作政治故事上可以任意拆掉的装饰。

作品整体同时牢固属于成人动作奇幻、城市政治悲剧、阶级冲突、科技伦理与电子游戏改编。文类内百合在这里回答“女女关系是否组织全作”，不声称“恋爱是唯一或主导文类”，也不覆盖其他类型。Mel／Jayce 位于副线，没有取代女女关系中心；若只能给出一个最能说明观看体验的类型，动作奇幻或政治悲剧仍可能更直接，百合推荐则需要注明姐妹主线、潜在恋爱副线和异性关系内容。

第三层：角色身份

第一季没有让 Vi 或 Caitlyn 自述女同性恋、双性恋或其他性取向，也没有范围内官方身份设定。Vi 的调情、Caitlyn 对“我们”的追问和 Jinx 的第三方 girlfriend 称谓支持具体关系方向，却不能替角色完成身份认定。Mel 与 Jayce 的异性关系同样只证明这段关系存在，不能穷尽任何角色的性取向。

第四层：公共标签礼仪

普通推荐可写“成人动作奇幻与城市政治悲剧；女女关系为主线，核心含姐妹亲情，Vi／Caitlyn 有潜在恋爱副线”。数据库可以使用“文类内百合”，但必须保留上述限定；若查询只收明确女女恋爱，则第一季不符合。私人百合阅读既可关注姐妹悲剧，也可关注 Vi／Caitlyn 的恋爱方向，但两者类型必须分开。官方查询应写“所核官方资料未使用百合／GL 字面；官方第一季回顾描述 Vi／Caitlyn 为正在萌发的关系”。Bangumi 的用户标签只证明公共阅读入口存在，不承担官方认证、作品事实或角色身份判断。

最强反方解释

最强的替代读法认为，《Arcane》首先是阶级政治、科技伦理、犯罪组织与战争升级的成人动作悲剧。Vi／Jinx 是姐妹，不能满足恋爱限定的百合查询；Vi／Caitlyn 在第一季也可能被看作高压任务中迅速形成的亲密搭档，因为双方没有告白、接吻或正式关系，girlfriend 只是 Jinx 在嫉妒与控制中的第三方称谓。与此同时，Mel／Jayce 拥有比任何女女关系更明确的性与恋爱情节。因此，把第一季不加限定地推荐成“明确 GL”会误导读者。

这项解释能推翻“第一季已有女女情侣”“角色身份已经明示”“恋爱是全作最主要类型”和“官方标注百合”等更强主张，也要求公共推荐保留动作政治类型与男性恋爱副线。但它不能解释掉 Vi—Powder／Jinx 对双主角成长和结局的作用，也难以把 Vi 的调情、Caitlyn 的关系追问及二人进入季终强迫选择全部解释成纯任务合作。只有当“百合”被预先限定为明确女女恋爱时，这一反方才会改变答案；对于“女女关系是否组织全作”这个问题，它构成必要限定，却不足以推翻文类内百合结论。
