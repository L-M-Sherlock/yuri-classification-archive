无剧透结论

按本档案采用的开放口径，《Arcane》第一季属于女性关系主线且按作品分类归档，置信度高：Vi 与 Jinx／Powder 的姐妹关系从开场一路决定寻找、重逢和最终选择，Vi 与 Caitlyn 的亲近又进入这条核心冲突。按作品归档判断因此建立在女性关系共同承担叙事结构上，其中最重要的一条明确是亲情，并非把姐妹爱误称为恋爱。

恋爱问题需要另答。Vi 与 Caitlyn 有直接调情、相互保护和关于“我们”的关系追问，足以标作潜在女女恋爱；但第一季没有双方告白、接吻、正式交往或性取向自述。它适合接受关系尚未确认的读者，不满足只收明确情侣的严格检索。Netflix／Riot 的公开分类未使用百合或 GL，Bangumi 的“百合”则是用户标签，二者可以同时成立。

Vi／Caitlyn。 二人从执法者与囚犯的利益合作开始。第 5 集的直接外貌调情和“男人还是女人”把可能的欲望引入正篇；互相救助、分享童年创伤和继续共同行动则建立信任。第 8 集的 What about us? 说明 Caitlyn 关心的不只是任务是否失败，Vi 也用“我们不该在一起”回应。季终由 Jinx 用 girlfriend 命名这种威胁，同时迫使 Vi 在两段女性关系间选择。

这些证据足以把 Vi／Caitlyn 记作明显但尚未确认的恋爱方向，却不足以写成“第一季已经交往”。最强的直接恋爱称谓来自第三方，双方本人没有告白、接吻、正式关系名称或身份标签。报告因此既不把二人降为普通临时同盟，也不借第二季替第一季完成确认。

Mel／Jayce。 两人在第五集进入明确的异性性亲密关系，政治合作与感情随后互相影响。它是有实质篇幅的副线，不是只有一句玩笑；但季终的最大关系选择、开火决定和结尾仍由 Vi、Jinx 与 Caitlyn 组成。故元数据记为 male_romance_line: secondary。

第二层：作品的文类位置

第一季最常规的主类型是成人动画、动作奇幻、城市政治悲剧、阶级冲突和电子游戏改编。若数据库只能给一个类型槽，这些标签通常比单写“百合”更能预测观看体验。

本档案仍把它列入广义的女性关系主线且按作品分类归档，依据不是 Vi／Caitlyn 一条副线，而是女性关系共同构成全季主干：

  1. 官方第一季简介、童年开场和季终都以 Vi／Jinx 姐妹为结构中心；
  2. Vi 寻找妹妹推动她穿过两城冲突，重逢与再次失去又决定季末结果；
  3. Vi／Caitlyn 的关系发展进入姐妹冲突，并在季终成为 Jinx 要求 Vi 作出的关键选择；
  4. Mel／Jayce 虽是明确异性副线，却没有取代上述结构。

这项分类必须带“广义关系口径”限定。若某数据库把“百合”严格定义为女女恋爱作品，则第一季最准确的结果应是“不满足”，而不是勉强把姐妹情当作恋爱或提前调用第二季。

第三层：角色身份

第一季没有让 Vi 或 Caitlyn 自述女同性恋、双性恋或其他性取向。Vi 的直接调情、Caitlyn 对“我们”的追问和 Jinx 的第三方 girlfriend 称谓，可以支持关系方向判断，不能替角色完成身份认定。两人身份依据均记为 unknown。

同理，Mel 与 Jayce 的异性亲密关系能证明这段具体关系存在，不能单凭一段关系推导角色全部可能的性取向。作品标签、具体关系和角色身份是三个不同字段。

第四层：公共标签礼仪

  • 普通推荐：写“成人动作奇幻／城市政治悲剧；姐妹关系是主线，Vi／Caitlyn 有未确认的女女恋爱发展”。

最强反方解释

最强的非女性关系主线归档解释认为，《Arcane》首先是阶级政治、科技伦理、犯罪组织与战争升级的成人动作悲剧。Vi／Jinx 是姐妹，不能满足恋爱限定的百合；Vi／Caitlyn 在第一季也可以被解释为高压任务中迅速形成的亲密搭档，因为双方没有告白、接吻或正式关系，girlfriend 只是 Jinx 的讥讽与嫉妒。Mel／Jayce 反而拥有明确的性关系。因此，把第一季放入不加说明的“百合番”列表会误导只找 GL 的读者。

这项解释足以推翻“第一季已确认女女恋爱”“角色身份已明示”和“官方标百合”，也说明为什么普通推荐不能只写“百合”。它不能推翻姐妹关系对全季的结构中心性，也很难把 Vi 的直接调情、Caitlyn 的 What about us? 以及季终的关系竞争全部解释成纯粹任务用语。分歧最终在于标签要检索“已确认女女恋爱”，还是也容纳“女性关系构成叙事中心”的开放文类。
