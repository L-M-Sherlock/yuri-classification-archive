动画字幕获取与审计

INSTALL

通过 Codex 安装

在 Codex 中让系统自带的 $skill-installer 从公开仓库安装。安装器遇到同名目录会停止，不会覆盖现有 skill。

安装全部三个

Use $skill-installer to install the skills from L-M-Sherlock/yuri-research-skills at skills/acquire-anime-subtitles, skills/classify-yuri-work, and skills/chrome-refresh-anime-platform-data.

固定首个稳定版本

Use $skill-installer to install from L-M-Sherlock/yuri-research-skills at ref v1.0.0 and choose the skill paths I name.
